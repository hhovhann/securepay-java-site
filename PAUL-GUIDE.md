# Updating the SecurePay website: a guide for Paul

You update the website by asking Claude in plain English, the way you would ask a colleague. Claude makes the change, checks it, shows you a preview, and sends it for approval. You don't need to touch any code.

## Where you ask

Use whichever is set up for you:

- **GitHub:** open a new issue on the website project, write your request, and include `@claude` in it. Claude replies on the issue and opens the change for approval.
- **Claude app:** open the SecurePay website project in the Claude app (desktop or web) and type your request.

## How to ask

Say **which page**, **what to change**, and give the **exact new words**. One request can contain several changes.

Examples you can copy:

- "On the Services page, under Payment Links → FlexiPay, add this point: *…new point…*."
- "On the About Us page, change the first paragraph to: *…your new text…*"
- "Change the Sales phone number everywhere from +971 50 478 0251 to +971 …"
- "Remove the Meraas logo from the home page."
- "Replace the Contact Us page image with the attached photo."
- "On the home page, change the number of Hotels Served from 475+ to …"
- "Fix a typo on the Partners page: *…* should be *…*."
- "In the About Us text, add this sentence with a link: *…exact sentence…* linking to https://…"
- "Create a new page called *Case studies* with this heading and text: *…*, and add it to the menu."
- "On the Services page, show Revenue Assurance before Gateway and APIs."

Tips:

- **Paste the exact words.** If you describe the change instead ("make it shorter"), Claude suggests wording and waits for your OK.
- **Attach images** when you want a new picture or logo.
- Not sure where something is? Ask: "Where on the website do we mention PayMatch?"

## What you can change

Everything you can see on the website. Page by page:

| Page | You can change |
| --- | --- |
| **Every page** | menu links, footer links and contact details, logo, LinkedIn link, copyright line, each page's search-engine title and summary |
| **Home** | headline and intro, the two buttons, the four workflow stages and their explanations, the eight published numbers, hotel-group logos (add, remove, reorder), Services cards, Benefits cards and points, About section, SecurePay Guide example, Want a Demo? bar |
| **About Us** | heading and text, image, the four facts, the six "Why Work With Us?" cards |
| **Services** | heading and intro, image, each service's text, its groups and their points (add, remove, reorder), the order of the services |
| **Contact Us / Partners** | heading and text, image, partnership categories, contact details shown next to the form. The forms themselves are managed in HubSpot. |
| **Privacy Policy / Terms** | only with approved legal wording or a new approved PDF |
| **SecurePay Guide (chat)** | the welcome message, suggested questions and the published facts it answers from |
| **New pages** | create a page from ready-made blocks (heading, image, facts, cards, detailed sections, text, Want a Demo? bar), link it from the menu, footer or any page, or remove it again |

## What happens next

1. Claude finds the text, makes the change, and runs the checks (links work, images exist, nothing else changed).
2. Claude shows you **Before / After** for each change and a preview link or screenshot.
3. You reply "yes" (or ask for adjustments).
4. Claude sends the change for approval. Text and image changes can be approved by you; anything touching the website's code goes to Phil.
5. Once approved, the change goes live with the next website update.

## What Claude will not do

- **Make things up.** Claude will never invent text, numbers, customer names, logos or claims. If something is missing, it asks you.
- **Change legal wording** (Privacy Policy, Terms & Conditions) without the approved text from you.
- **Change the forms** or where their submissions go: that is set up in HubSpot.
- **Change the design or the page layouts**, add forms, or create a new kind of block. That is a job for Phil. Claude will tell you so and can write the request for him.

## Good to know

- Every change is recorded, so any change can be undone. Ask "Undo the change to the About Us page from yesterday."
- The SecurePay Guide (the chat on the site) answers from published facts. If you change a fact on a page, Claude will offer to update the Guide's answer too.
